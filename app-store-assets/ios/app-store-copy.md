## Description

Cybara is the mobile companion for your Cybara gateway: a private, open-source AI agent platform for running multi-model agents across local tools, channels, and workflows. Connect to a gateway you control, start and monitor chats, review model and provider activity, check system health, manage tasks, and keep research or engineering work moving from iPhone and iPad.

With Cybara Mobile, you can:

- Chat with configured agents and models from your gateway.
- Monitor active sessions, recent activity, tools, and gateway health.
- Review token usage, provider activity, storage, API calls, and system metrics.
- Manage tasks, memory, channels, wallet policy, and approvals from a mobile-first interface.
- Pair securely with a revocable mobile device token instead of sharing your root gateway key.

Cybara Mobile requires a running Cybara gateway. Some features require configured model providers, enabled tools, and gateway permissions.
